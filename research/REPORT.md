# Отчет по предметной области

## Покрытие

- База: 2381 строка. Служебные (перевозка, погрузка, надбавки, ресурсы) — 108, товарные — 2273.
- Категорий: 130 (107 с позициями в базе, из них 4 служебные; 23 без позиций, включая 21 добавленную при исследовании) — `categories.yaml`. Триггерами классифицировано 2156 из 2273 товарных строк — **94,9 %**; 117 строк — «прочее».
- Точность классификации по выборке из 100 случайных строк — около 95 % (4–5 ошибок; типовые — в `traps.md`, пп. 1–16).
- `attributes.yaml`: 108 категорий, 334 характеристики; у каждой — уровень (статус «предложено»), сравнение, ряд, замена, источник, уверенность и число строк базы (подсчитано регулярными выражениями, оценка грубая).

## Что не описано

- 117 строк «прочее» (единичные изделия: станки, мебель, спецоборудование).
- Характеристики не выделены для 22 категорий, где товар задается моделью или функцией: АРМ, приборы, системы мониторинга, ВЧ-аппаратура, инструмент, ограждения (список в конце `attributes.yaml`).
- Не подтверждены источником: ряд мощностей сухих трансформаторов (ГОСТ Р 54827 не открыт), ряд жильности КВВГЭ, коды `/16`, `/71` в ЗПС/ЗНС, `ГВ-4534-04`, `SKAT-V.12DC-18 исп.5М`, ранг очага огнетушителя ОП-5.
- Составные позиции «в составе:» / «комплектно с:» (138 строк) — правило не выработано, вынесено в вопросы.
- Счетчик строк для «класс бетона» и некоторых кодовых характеристик дает ложные срабатывания.

## Выводы

1. Тип изделия обычно определяется первыми словами строки, но короткие марки (`КГ-`, `ОП-`, `ЗПС`, «опора», «камера», «автомат») дают ложные категории — нужны анти-триггеры и проверка вместе с характеристиками.
2. Числа без категории неразличимы: `850` — цветность у светильника, `7` — тс у звена ПТМ, `0,78` — диаметр жилы у КИП, `1000` — вольты у кабеля и ток у разъединителя. Разбор чисел — только после категории.
3. Около 5 % строк содержат конфликт текста и кода модели или альтернативу в «(прим. …)». Их нужно помечать, а не выбирать одно значение молча.
4. По 4 из 7 эталонных запросов точного аналога в базе нет, есть близкий с одним отличием (экран у КВВГ, мощность у ТСЗ, материал у гофры, исполнение у ИБП). Главное для пользы — честно показывать отличие.
5. Ключевые решения (экран, FRLS вместо LS, ступень мощности, уличное исполнение) нормативные, а не технические; без специалиста их не зафиксировать (см. `questions_for_specialist.md`).
